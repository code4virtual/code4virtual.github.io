Our aim

めざすこと

Code for X は、市民自身がテクノロジーで地域や社会の課題を解こうとする活動の呼び名です。その多くは「地域」を単位にしています。

私たちがやってみたいのは、その活動をバーチャル空間を拠点にして進めることです。VRChat や cluster のような場所には人が集まっていて、現実のまちと似た課題も生まれています。同時に、距離や身体の制約を越えて人が集まれる場所でもあります。そこを拠点にしたシビックテックがどんな形になりうるのか、確かめたいと考えています。

ただし、これはいまのところ意図であって、実績ではありません。何から手をつけるか、どのプラットフォームを使うか、どんな頻度で集まるかは、まだ何も決まっていません。関心を持つ人が集まってから決めていきます。
