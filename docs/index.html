About us

「Code for X」を、バーチャル空間から。

Code for X は、市民自身がテクノロジーで地域や社会の課題を解こうとする世界的なムーブメントです。その多くが「地域」を単位にしているのに対して、私たちが拠点にするのはバーチャル空間そのものです。

バーチャル空間には、すでに人が集まり、文化が育ち、経済が動いています。同時に、アクセシビリティ、居場所づくり、権利やルール、デジタル格差といった、現実のまちとよく似た課題も生まれています。

Code for Virtual は、そうしたバーチャル空間の課題に取り組むと同時に、バーチャル空間から現実の社会課題に取り組みます。距離や身体の制約を越えて集まれることは、シビックテックにとって大きな強みだと考えているからです。

議論だけで終わらせず、小さくてもいいから動くものをつくる。それが私たちの基本的なスタンスです。

  • 01

    つくりながら考える

    要件定義から始めない。まずプロトタイプをワールドに置いて、集まった人に触ってもらうところから始めます。

  • 02

    誰も置いていかない

    ハイスペックPCがなくても、声を出せなくても、実名でなくても参加できる設計を最初から考えます。

  • 03

    成果はみんなのものに

    コード・3Dアセット・ドキュメントはオープンライセンスで公開し、他の地域やコミュニティが再利用できる形にします。

What we do

6つの活動領域

関心のある領域だけの参加で大丈夫です。複数を横断するプロジェクトもあります。

オープンデータの可視化

自治体が公開する人口・交通・災害データを、バーチャル空間で歩いて体験できる3Dの形に翻訳します。グラフを見るのではなく、その中を歩けるように。

防災・減災

浸水想定や避難経路をVRで疑似体験できるコンテンツ、災害時のバーチャル避難所の運用ルールづくりなど、「その時」に効く備えを検討します。

アクセシビリティ

字幕・読み上げ・低負荷モード・座位での移動など、バーチャル空間を誰にとっても使いやすくする実装知見を集めて共有します。

教育・学びの場

プログラミング、3Dモデリング、シビックテックの入門講座をバーチャル空間で開催。教室に通えない人にも届く学びの形を試します。

ワールド／空間づくり

公共施設や商店街のバーチャル再現、市民が集まれる広場ワールドの制作。空間そのものを公共財として設計します。

コミュニティ運営の研究

荒らし対策、モデレーション、安全な場のつくり方。バーチャル空間で人が安心して集まるための運営ノウハウを言語化して公開します。

Meetup

定例会のながれ

毎週オンラインで集まっています。開催日時と集合ワールドはコミュニティ内で告知しています。以下の時間は開始からの経過時間です。

  • 00:00 — 00:10

    集合・自己紹介

    初参加の方から一言ずつ。名前と、興味のある分野だけで大丈夫です。

  • 00:10 — 00:30

    共有タイム

    各プロジェクトの進捗、見つけた面白いデータや技術を持ち寄って共有します。

  • 00:30 — 01:20

    もくもく／ハック

    それぞれ手を動かす時間。詰まったらその場で相談できるのがバーチャル集会の良いところです。

  • 01:20 — 01:30

    ふりかえり・解散

    やったことを共有して終了。そのまま残って雑談する人も多いです。

持ち物は必要ありません。

VR機器がなくても、PCやスマートフォンからデスクトップモードで参加できます。マイクが使えない場合はテキストチャットでの参加も歓迎です。

技術的な経験は問いません。企画、デザイン、文章、モデレーション、「使ってみて感想を言う」役割も、プロジェクトには等しく必要です。

初めての方は、まず 参加のしかた をご覧ください。

Join us

参加のしかた

入会手続きや会費はありません。次の3ステップで、今週から参加できます。

  1. コミュニティに入る

    チャットコミュニティに参加して、自己紹介チャンネルで挨拶をしてください。告知はすべてここで行っています。

  2. 定例会をのぞく

    告知された時間に集合ワールドへ。聞くだけの参加も歓迎です。雰囲気を見てから決めてください。

  3. 気になることを始める

    既存プロジェクトに合流してもいいし、新しく立ち上げてもかまいません。「やりたい」と言った人が発起人です。

つくりたいものが、まだなくてもいい。

課題を持っている人、技術を持っている人、場を温める人。その全部がそろって、はじめてシビックテックは動きます。まずは会いに来てください。

FAQ

よくある質問

VR機器を持っていなくても参加できますか？

できます。VRChat も cluster も、PCやスマートフォンからデスクトップモードで参加できます。実際、メンバーの多くはヘッドセットなしで参加しています。

プログラミングができなくても大丈夫ですか？

大丈夫です。課題の整理、資料づくり、デザイン、イベント運営、広報、そして「使ってみて感想を伝える」ことも、プロジェクトに欠かせない役割です。

本名や顔出しは必要ですか？

必要ありません。ハンドルネームとアバターでの参加が基本です。バーチャル空間の匿名性は、参加のハードルを下げる大切な性質だと考えています。

費用はかかりますか？

コミュニティへの参加・定例会への参加はすべて無料です。特定のイベントで実費が必要な場合は、事前に明記します。

自治体や企業として相談したいのですが。

歓迎します。オープンデータの活用、バーチャル空間での市民参加イベント、職員向けの体験会などのご相談は、お問い合わせ先までご連絡ください。

作ったものの権利はどうなりますか？

原則としてオープンライセンスで公開し、誰でも再利用できるようにします。ライセンスはプロジェクトごとにリポジトリで明示します。
